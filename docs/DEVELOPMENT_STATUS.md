# Development status

## Phase 1: Foundation (done, confirmed running on the user's Windows PC)
Project schema + migration, project manager (create/open/save/save as/autosave/recovery/backups), undo/redo, secure IPC, layout shell, timeline tracks, playhead.

## Phase 2: Media management (code complete; real-file tests pass)
- Import via native dialog (multi-select) and drag-and-drop; formats MP4, MOV, MKV, PNG, JPG/JPEG, WAV, MP3, AAC (+M4A).
- FFprobe metadata: kind, duration (integer ms), resolution (rotation-aware), exact fps fraction, codecs, sample rate, channels, size.
- Thumbnails (video frame, image, audio waveform) generated by FFmpeg, max 2 jobs at a time, stored in assets/thumbnails, sent to the UI as small data URLs.
- Media / Images / Audio library panels with cards, details, duplicate detection, per-file failure reporting.
- Source files are referenced, never copied or modified. Inside-project files use relative paths, others absolute.
- Missing-media detection (on load, on change, on window focus) and relinking (keeps the asset id, refreshes metadata, kind must match).
- 540p H.264 proxy generation with cancel, written to assets/proxies via temp file + rename.
- Project schema v2 (adds `media`); v1 projects migrate automatically.
- FFmpeg/FFprobe: env var override, then system PATH, then bundled fallback packages.

## Phase 3: Timeline clips (code complete; logic tested; window interactions not yet run on Windows)
- Project schema v3 adds `clips` (track, asset, start, source in, duration, all integer frames). v1/v2 projects migrate; clips pointing at a missing track/asset are dropped on open.
- Place clips by dragging library cards onto a track lane (ghost preview), double-click a card, or the + button on a card (adds at the playhead on the first fitting unlocked track).
- Move clips (also between compatible tracks), trim left/right edges, snapping to clip edges, playhead and zero (magnet toggle, amber guide line), Esc cancels a drag. One drag = one undo step.
- Rules enforced everywhere: no overlap on a track (moves/adds go to the nearest free slot), trims stay inside the source file and off neighbours, video/image on video+overlay tracks, audio on audio tracks, locked tracks refuse edits.
- Split at playhead (S), duplicate (Ctrl+D), delete (Delete), arrow keys/Shift+arrows/Home move the playhead, Fit button, timeline grows with content.
- Clip properties tab: start, duration, source in (frames with timecode), source out, Split/Duplicate/Delete.
- Changing the project frame rate converts all clips; removing media asks first and deletes its clips; relinking to a shorter file clamps clips.

## Phase 4: Preview (code complete; logic and server side tested; actual playback in the window not yet run on Windows)
- The preview composes what is under the playhead: every video/image clip on visible video and overlay tracks, stacked with the **first timeline row on top**, letterboxed (`contain`) inside the project's aspect ratio. Hidden tracks lose their picture but keep their sound; muted tracks are silent; overlay-track sound is left out of the preview mix.
- Play/Pause (button or Space), Home, frame step (arrows, Shift = 1 s), ruler scrubbing, timecode with total length, mute, proxy toggle. Playback follows a real-time clock driving the integer-frame playhead; seeking during playback re-anchors it; it stops on the last frame; the timeline scrolls to follow the playhead.
- Audio clips play through hidden audio elements. Upcoming clips (next 2 s) are preloaded and parked on their first frame.
- Media reaches the page through a private `r0bi-media://` protocol with HTTP range support (needed for seeking). It only serves files in the open project's library; proxies are used when available (toggle).
- Files the player cannot decode show a message suggesting a proxy.

## Phase 5: Audio and subtitles (code complete; logic and file handling tested; interaction not yet run on Windows)
Audio
- Per-clip volume (0-100%) and linear fade in/out, per-track level, mute; a Mixer list in the Audio tab. The preview applies clip x track x fade level every frame.
- Waveforms on audio clips (real peaks, one per 20 ms, cached in assets/waveforms, drawn for the part of the file the clip plays); fades drawn as dark ramps.
- Sync tools for any clip: nudge by -1 s / -1 f / +1 f / +1 s, "Start at playhead"; nudges stop against neighbours instead of overlapping.
- Fades stay inside the clip through trims, splits (fade-in stays left, fade-out goes right) and frame-rate changes.
Subtitles
- Subtitle cues on subtitle tracks (project schema v4), shown as blocks on the timeline: drag, trim (snapping like clips), double-click an empty spot to add one; no overlaps on a track.
- Subtitles panel (left): Import SRT, Add, per-track list with inline text editing, click to jump, active row highlighted. Import goes into an empty subtitle track (a new one if needed) so it can never overwrite existing subtitles; handles UTF-8/UTF-16, BOM, CRLF, "." or "," decimals, multi-line text, strips simple markup, repairs overlaps.
- Subtitles tab (right): selected cue text/start/duration/nudge/duplicate/delete, and track style: font (any name, Khmer-capable fallbacks always added), size, bold, colour, outline width+colour, background colour+opacity, vertical position. Live in the preview.
- Slider drags and typing merge into one undo step. v1-v3 projects open unchanged.

## Phase 6: Export (code complete; the whole render pipeline is tested with real FFmpeg; the dialog and subtitle drawing not yet run on Windows)
- Export dialog (Export button or Ctrl+E): resolution (project size, 720p, 1080p, 1440p, 2160p; presets name the shorter side), quality (Draft/Standard/High = x264 CRF 28/23/18 or NVENC CQ 32/26/21), encoder (Automatic/CPU/NVENC), file name, output folder (project `exports/` or a chosen folder). Always H.264 + AAC 192 kb/s 48 kHz stereo, MP4 with faststart, at the project's frame rate.
- Export queue (one job at a time): live progress and time left, cancel (running or waiting), clear finished, show in folder, errors in plain language, OS notification when done or failed, quit/close warning while exporting. The Export button shows the running percentage.
- The render builds one FFmpeg filter graph from the timeline: black canvas, every video/image clip stacked in track order (first row on top), letterboxed with transparent bars exactly like the preview, hidden tracks skipped, subtitles on top; sound = each clip levelled by clip x track volume, faded, placed at its start and mixed at true levels, muted tracks and overlay tracks silent. Clips are cut at their exact source in-point.
- Subtitles are drawn by the app (canvas, same look as the preview incl. outline, background box, Khmer shaping) and overlaid as images, so FFmpeg's font/libass support is not needed.
- Safety: renders to `<name>.mp4.partial`, checked with FFprobe (size, H.264, AAC, frame rate, length) and renamed only if it passes; cancel or failure deletes the partial; missing media is named before anything starts; originals and proxies are never used for output (originals only); NVENC is only used if a real test encode works, and a failed GPU encode is retried once on the CPU.

## Phase 7: AI assistant (code complete; command language, executor, key storage and API client tested; the panel and Settings dialog not yet run on Windows; never tested against the live Claude API)
- Optional: with no key the editor is unchanged. Settings (top bar gear): paste an Anthropic API key (stored encrypted with Windows safeStorage in the app's private folder, never in projects, never sent back to the page; only a hint like `sk-ant-…1234` is shown), choose a model, Test connection, Remove key, privacy notes. If the computer cannot encrypt, saving a key is refused.
- Assistant tab (right panel): chat with six one-click ideas from the spec ("Make this video more exciting", "Synchronize the narration with the scenes", "Add subtitles from my script", "Shorten the introduction", "Increase the music slightly", "Make the transitions smoother"), Stop button, optional "send small thumbnails" checkbox (off by default).
- Workflow: request -> project context -> Claude plan -> schema validation -> dry run with a plain-language step list -> user review -> Apply -> timeline changes as ONE undo step. Plans are all-or-nothing and re-checked against the project at apply time. A failed plan shows which step failed and offers "Ask the assistant to fix it".
- Commands (strict schema, unknown or extra fields rejected): trim_clip, move_clip, split_clip, delete_clip, duplicate_clip, add_transition (fade_in, fade_out, dip_to_black, hard_cut), set_volume (clip volume/sound fades or track level), add_audio (existing library audio only), add_subtitles, update_subtitles, set_export_settings (changes the export dialog only). The model sees short ids (t1, a1, c1, s1) and metadata only: no paths, no media, real ids never leave the app. Things created by earlier commands get predictable names (c3.b, c3.copy, new1, newcue1, newtrack1).
- The model can never run commands or touch files: it returns data in the schema, and the app applies it with the same pure timeline functions used by manual editing. Text inside the project (clip names, subtitle text, scripts) is marked in the system prompt as content, not instructions.
- New in the editor (needed by add_transition): picture fades per clip (fade from black, to black, dissolve over a lower layer, dip to black across a cut) in the Transition tab, shown as ramps on clips, working in the preview and in the exported video. Project schema v5.

## Phase 8: Automation (code complete; logic and the real render of an assembled project tested; the panels not yet run on Windows)
- Left sidebar "Automation" tab (the old Templates tab) with Assemble / Templates / Scenes, plus presets and batch export in the Export window.
- **Automatic scene assembly:** click library videos/images in play order (or "Use all"), pick narration and music, set the recipe (track names, still-image length, scene fade, narration/music level, music fades, "stretch stills to fit the narration"), choose replace or append, press Assemble. Videos play in full, stills share the narration length (or use the default), every scene fades from/to black (dip between scenes), narration and music go on their tracks, music is cut to the video length. One undo step, with a plain-language report and notes (e.g. "music is shorter than the video").
- **Episode templates:** saves a project's tracks, levels, subtitle looks, resolution/frame rate, export settings and assembly recipe (never clips). "Apply here" adds missing tracks and copies looks without touching clips (size/fps only change while the project is empty); "New project..." creates a project folder and applies the template.
- **Reusable scenes:** save any time range of the timeline (cut edges, fades only kept on real clip edges, subtitles included) to a library shared by all projects; "Insert at playhead" finds the first free spot (adds tracks if needed, converts frame rate, clamps to the source), imports media the project lacks, and does import + placement as one undo step.
- **Production presets:** built-ins (YouTube 1080p High, Review draft 720p, 4K master) plus your own saved from the Export window; picking one sets resolution/quality/encoder.
- **Batch export:** Export window -> Batch export...: tick the open project and/or other project files (picked with a file dialog), tick presets, choose each project's own exports folder or one folder; queues one export per project per preset ("Project - preset.mp4") through the same verified queue. Other projects are opened read-only; their folders stay in the main process.
- Saved templates/scenes/presets live in the app's data folder (`library/*.json`), validated on load (damaged entries are dropped).

## Fix release before Phase 9 (found by the user on Windows)
- **Effects tab was a leftover placeholder.** It is now a real panel: Quick moves (slow zoom in/out, strong zoom, pan left/right/up/down), Opacity, Zoom (start/end, 100-400%), Position (start/end across and up/down), Fade from/to black, Hard cut, and Dissolve into next clip. Effects work in the preview (CSS transform and opacity) and in the exported video (FFmpeg `zoompan` with a 2x pre-scale for smooth motion, `colorchannelmixer` for opacity, animated overlay offsets for position). Clips with effects show an "FX" badge; a split carries the animation on smoothly. Project schema v6 (optional `effects`).
- **Dissolve into next clip:** the next clip moves up to the nearest free video track (or a new one) and starts a little early using its own lead-in footage, fading in over the end of the first clip, so nothing after it shifts. It explains why when the next clip has no lead-in footage.
- **Scenes tab was also a placeholder.** It is now a Scene Manager: pick a video track and see its clips as a storyboard (thumbnail, time, length); reorder (move earlier/later, in place), duplicate, split at the playhead, delete or delete-and-close-the-gap, close gaps, add a scene from the library, set In / Out / Length, and write a note per scene.
- **AI assistant errors are now specific.** Messages include the HTTP code and explain the likely cases: no API credit (API use is billed separately from Claude Free/Pro/Max chat plans), key rejected, model not found, request refused (key access/region), rate limit, Anthropic busy. The Assistant tab has a Test connection button and an Open Settings button on every error. Verified: the tool JSON Schema is valid strict JSON Schema 2020-12; the client works over real HTTP against a stand-in server.

Still disabled (later phases):  scenes/effects/subtitles/templates panels, AI tab.
